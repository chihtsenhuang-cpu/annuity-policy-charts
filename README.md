## 三個指標的定義

四家建議書的欄位名稱各不相同，統一對應成三個指標：

**A 累積領回** — 到該年齡為止已經領到手的現金總額

- 保誠：累積生存保險金 ＋ 累積年度紅利
- 台壽：累計已領生存保險金（含累計增加保險金額）
- 新光：生存保險金＋增加回饋金合計金額逐年累加
- 全球：年度末生存保險金逐年累加

**B 當年度解約可拿** — 該年度末解約，保單退還的金額

- 保誠：當年度末解約金 ＋ 長青解約紅利
- 台壽：保單現金價值（解約金）
- 新光：總領解約金額（含增額繳清）欄位減去 A
- 全球：年度末解約金

**C 總價值** — A ＋ B。四張保單領回方式不同（現金給付 vs 購買增額繳清），單看 A 或單看 B 都不對等，C 才是可比的基準。

## 保費換算

為了讓四張在同一個保費基礎上比較，全部換算成年繳 600,000 元 × 6 年（累計實繳 3,600,000 元）：

| 商品 | 原始年繳 | 係數 |
|---|---|---|
| 保誠 | 600,000 | 1.0（未調整） |
| 台壽 | 600,000 | 1.0（未調整） |
| 新光 | 596,917 | ×1.005165 |
| 全球 | 604,125 | ×0.993172 |

等比例縮放不改變各商品的給付結構，但實際投保時保額須依保費重新計算，金額會有尾差。

## 資料涵蓋範圍

各商品建議書的表格長度不同，取到各自最後一列有效資料：

- 保誠 48–109 歲。109 歲（第 62 年度）解約金欄位為祝壽保險金，予以保留。
- 台壽 48–98 歲。建議書表格至 99 歲止，該列生存保險金與解約金皆為 0，屬結尾列，不採用。
- 新光 48–108 歲。109 歲解約金欄位為 0，祝壽保險金未列於該欄，不採用。
- 全球 48–108 歲。同上。

保誠的年度現金流圖同樣統計至 108 歲——109 歲生存保險金歸零改給祝壽保險金，金額會斷崖式下墜。

## 資料驗證

數字由建議書 PDF 以座標定位方式抽取，並用表內既有的加總關係逐列交叉驗算：

- 保誠：A+G、B+G、C+E 三個合計欄位、累積生存保險金、累積年度紅利，62 列全數相符
- 台壽：累計已領生存保險金 = 逐年生存保險金累加，52 列相符
- 新光：合計金額 = 基本保額對應生存金 ＋ 增額保額對應生存金；累加值與表列末列 3,905,151 完全相同
- 全球：以年度末解約金與生存保險金直接取用，表上已註明解約金不含當年度生存保險金，無重複計算

## 注意

各商品的紅利、增值回饋分享金、增加回饋金均屬**非保證給付項目**，依各建議書所載假設利率或假設分紅試算。實際金額可能較高或較低，保險公司不保證其給付金額。
